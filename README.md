# krystian-gwizdala.github.io

The portfolio of Krystian Gwizdala.

It sits on a hostname of its own because Google assigns one site name and one favicon **per hostname**, never
per subdirectory. At the previous address, `krystiangw.github.io/krystiangw/`, every result inherited the name
and icon of the unrelated site that owns the root of that host: it showed up in search as "Gabinety CBT na
Wroclawskiej".

`icon.svg` is a placeholder monogram in the site's own palette. Replace it whenever there is a real mark; it
is what Google shows next to the result.

The old address serves a `canonical` and a `meta refresh` pointing here. GitHub Pages cannot return a 301 for
a project path, so the move is slower than a real redirect and the old URL keeps its ranking for a while.
